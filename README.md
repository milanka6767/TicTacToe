# Руководство пользователя: Игра «Крестики-Нолики»

# 1. Запуск игры и главное окно
# После запуска приложения открывается главное окно игры:
 - В центре расположено игровое поле, состоящее из 9 пустых квадратных кнопок (сетка 3х3).
 - В левом нижнем углу находится счетчик хода («Ход: X»), который показывает, чей сейчас ход.
 - В самом низу расположена кнопка «Начать заново» для сброса текущей партии.
 - Сверху расположено информационное поле для вывода результатов (победы или ничьей).

# 2. Как играть
 - Игра всегда начинается с хода игрока «X».
 - Чтобы сделать ход, нажмите левой кнопкой мыши на любую пустую кнопку на игровом поле. В выбранной клетке появится ваш символ (X или O).
 - После хода выбранная кнопка блокируется, чтобы игроки не могли перезаписать уже занятую клетку.
 - Право хода автоматически переходит ко второму игроку, а надпись в левом нижнем углу меняется (например, с «Ход: X» на «Ход: O»).

# 3. Окончание игры
# Игра завершается, как только один из игроков собирает три своих знака в одну линию (по горизонтали, вертикали или диагонали), либо когда заполнятся все 9 клеток.

# 4. Перезапуск игры
# Чтобы начать новую партию, нажмите кнопку «Начать заново» в нижней части окна. Все кнопки на поле очистятся, счетчик хода сбросится на «Ход: X», и игра начнется сначала.
